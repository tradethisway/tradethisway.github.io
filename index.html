rclone-archive

rclone-archive is a private, single-user tool. It uses rclone to back up and archive files to the owner's own Google Drive. It is not offered to the public.

Privacy Policy

Last updated: November 12, 2026

Data accessed. The app requests the Google Drive scope drive.file, which only grants access to files the app itself creates or that the user explicitly opens with it. It does not access any other files in the user's Drive.

How data is used. Files are uploaded to and read from the owner's Google Drive solely to create and restore backups. Data is not used for any other purpose.

Storage and sharing. OAuth tokens are stored only in the local rclone configuration on the owner's own machines. No data is collected, stored on third-party servers, sold, or shared with anyone.

Google API Services. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access. Access can be revoked at any time at myaccount.google.com/permissions.

Contact. Questions can be raised via github.com/tradethisway.
